DI 生命週期、AutoMapper 設定、Web.config 轉換⋯⋯後端開發的眉角，踩過的雷都寫下來了。

Hexo 從零到部署的完整教學、Hugo 與 Jekyll 的快速上手，還有三者的比較心得。

### MongoDB 與資料庫

Docker Compose 搭建 MongoDB Sharding Cluster，NoSQL 的實戰筆記。
