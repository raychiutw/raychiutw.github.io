支援

找不到答案的話，請寫信到 lean.lean@gmail.com。方便的話附上 App 的「⋯ → Settings → Copy Diagnostics」(只有 App 與 iOS 版本、裝置種類、主機數量與 herdr 版本，不含主機名稱、位址或對話)。

需要準備什麼?

  • iOS 26 或 iPadOS 26 以上的 iPhone 或 iPad。
  • 一台跑著 herdr 0.9.5 以上的電腦(macOS、Linux 或 Windows),你的 coding agent 在 herdr 裡執行。
  • 從 iPhone／iPad 連得到那台電腦的 SSH:Tailscale SSH(不用金鑰或密碼)或 OpenSSH。
  • 推播通知是選用的，需要 Purrdr Plus。聊天與終端機不需要帳號也不需要訂閱。

還沒準備好也沒關係：App 第一次開啟時選「Try the Demo」,Demo 主機有範例對話，可以先試遍每個畫面。

用 Tailscale SSH 連線

  1. 電腦與 iPhone／iPad 都安裝 Tailscale,登入同一個 tailnet。
  2. 在電腦上開啟 Tailscale SSH(例如 tailscale set --ssh),並確認 tailnet 的 SSH 規則允許你的裝置以要登入的使用者連線。依 Tailscale 文件，Tailscale SSH 伺服器支援 Linux 與 macOS(macOS 需使用開源版 tailscaled);Windows 請改用 OpenSSH。
  3. 在 Purrdr 的「⋯ → Hosts → +」新增主機，連線方式選 Tailscale SSH,填入主機的 Tailscale 名稱或 IP 與使用者名稱。
  4. 第一次連線時核對並確認 host key 指紋。之後指紋改變，Purrdr 會停下來請你確認。

若 tailnet 的 SSH 規則設為 check 模式，Purrdr 會請你在瀏覽器完成 Tailscale 的重新驗證後繼續。

用 OpenSSH 連線

  1. 確認電腦的 SSH 伺服器已開啟(macOS:系統設定 › 一般 › 共享 › 遠端登入;Linux:sshd;Windows:OpenSSH Server)。
  2. 新增主機時連線方式選 OpenSSH,填位址、埠與使用者名稱。
  3. 驗證方式三選一：
    • 這支裝置的金鑰(建議):Purrdr 在裝置的 Secure Enclave 產生金鑰，畫面上會給你一行指令，把公鑰加到電腦的 ~/.ssh/authorized_keys(Windows 管理員帳號是 administrators_authorized_keys,畫面上有 PowerShell 指令)。
    • 匯入你自己的 OpenSSH 私鑰(ed25519 或 ECDSA)。不支援有 passphrase 的私鑰：先在電腦上執行 ssh-keygen -p -N "" -f <私鑰> 移除 passphrase 再匯入。
    • 密碼。
  4. 第一次連線時核對並確認 host key 指紋。

私鑰與密碼只存在這支裝置的 Keychain,不會上傳，也不會被主機同步帶到其他裝置。

Windows 主機支援到哪裡?

  • 經 OpenSSH 連線，App 以 PowerShell 執行指令，不需要 Git Bash。
  • 可以用：Agent 列表、聊天、回答提問、送 prompt 與圖片、Pane 終端機、資料夾瀏覽。
  • 還不支援：推播通知的設定，以及主題、Claude 用量、Codex 啟動器這類會寫入主機的功能(會顯示「This isn’t available on Windows hosts yet.」)。
  • 在 App 裡更新 herdr 後，Windows 沒有不中斷的接手，請在電腦上重新啟動 herdr 再測試連線。

推播通知怎麼運作?要裝什麼?

  • 需要 Purrdr Plus,且主機是 macOS 或 Linux(需要 sh 與 curl)。
  • 在「⋯ → Settings」為選取中的主機開啟通知。經你同意後，Purrdr 會在主機執行 herdr plugin install 安裝一個小型 herdr 外掛(公開原始碼:raychiutw/purrdr.host),並在 ~/.purrdr/ 寫入這支裝置的配對檔。
  • Agent 需要你時，外掛只送出 workspace 名稱、狀態與 pane id 給 Purrdr 的伺服器，再由 Apple 推播到你的裝置;對話內容不會送出。點通知會直接打開那個聊天。
  • 關掉通知或刪除主機時，Purrdr 會移除這支裝置的配對;最後一支裝置關掉時，也會移除 Purrdr 安裝的外掛。
  • Demo 主機不能推播，請先選你自己的主機。

訂閱 Purrdr Plus、管理與取消

  • Purrdr Plus 月繳或年繳，新訂閱者各有 2 週免費試用。內容是 Agent 需要你時的推播，以及在你的裝置之間同步主機清單。
  • 訂閱前要先以 Sign in with Apple 或 Google 登入會員(「⋯ → Member」),訂閱屬於這個會員。
  • 管理或取消：iOS「設定 › Apple 帳號 › 訂閱」,或 App 的「⋯ → Purrdr Plus → Manage Subscription」(訂閱中才會出現)。
  • 刪除會員不會取消 Apple 的訂閱，請另外取消。

恢復購買

  • 在新裝置或重新安裝後，先登入同一個會員，再到「⋯ → Purrdr Plus → Restore Purchases」。
  • 一個 App Store 訂閱只屬於一個 Purrdr 會員。若看到「這個 Apple 帳號的訂閱已屬於另一個會員」,請改用當初訂閱時的登入方式，或在 Member 頁把兩種登入方式連結到同一個會員。

兌換 Offer Code(優惠代碼)

  • 在 App 裡：登入會員後，到「⋯ → Purrdr Plus → Redeem Code」輸入代碼。
  • 從兌換連結或 App Store 兌換：兌換後打開 Purrdr、登入會員，訂閱會自動綁定;沒有出現的話按「Restore Purchases」。
  • 目前的優惠代碼只適用於從沒訂閱過 Purrdr Plus 的 Apple 帳號。

刪除會員與資料

「⋯ → Member → Delete Member…」會立即刪除會員、推播配對與同步的主機。詳見隱私權政策。

What do I need?

  • An iPhone or iPad on iOS or iPadOS 26 or later.
  • A computer (macOS, Linux, or Windows) running herdr 0.9.5 or later, with your coding agents running in herdr.
  • SSH access from your iPhone or iPad to that computer: Tailscale SSH (no keys or passwords) or OpenSSH.
  • Notifications are optional and need Purrdr Plus. Chat and the terminal need no account or subscription.

Not ready yet? Tap “Try the Demo” the first time you open the app — the Demo host has sample conversations, so you can try every screen first.

Connecting with Tailscale SSH

  1. Install Tailscale on the computer and on your iPhone or iPad, signed in to the same tailnet.
  2. Turn on Tailscale SSH on the computer (for example tailscale set --ssh) and make sure your tailnet’s SSH rules let your device log in as the user you want. According to Tailscale’s documentation, the Tailscale SSH server runs on Linux and macOS (on macOS, the open-source tailscaled variant); on Windows, use OpenSSH instead.
  3. In Purrdr, go to “⋯ → Hosts → +”, choose Tailscale SSH, and enter the host’s Tailscale name or IP and your user name.
  4. On the first connection, check and confirm the host key fingerprint. If it ever changes, Purrdr stops and asks you.

If your tailnet’s SSH rule uses check mode, Purrdr asks you to finish Tailscale’s re-authentication in the browser, then continues.

Connecting with OpenSSH

  1. Make sure the computer’s SSH server is on (macOS: System Settings › General › Sharing › Remote Login; Linux: sshd; Windows: OpenSSH Server).
  2. When adding the host, choose OpenSSH and enter the address, port, and user name.
  3. Pick one way to sign in:
    • This device’s key (recommended): Purrdr creates a key in the device’s Secure Enclave and shows a command that adds the public key to ~/.ssh/authorized_keys on the computer (for a Windows administrator, administrators_authorized_keys; the PowerShell command is shown).
    • Import your own OpenSSH private key (ed25519 or ECDSA). Keys protected by a passphrase aren’t supported: on the computer, run ssh-keygen -p -N "" -f <key file> to remove the passphrase, then import it.
    • A password.
  4. On the first connection, check and confirm the host key fingerprint.

Private keys and passwords stay in this device’s Keychain. They’re never uploaded and never carried to other devices by host sync.

How well are Windows hosts supported?

  • Connect over OpenSSH; Purrdr runs commands with PowerShell, so Git Bash isn’t needed.
  • Works: the agent list, chat, answering questions, sending prompts and images, pane terminals, and browsing folders.
  • Not yet: setting up notifications, and features that write to the host such as themes, Claude usage, and the Codex launcher (you’ll see “This isn’t available on Windows hosts yet.”).
  • After updating herdr from the app, Windows has no seamless handoff — restart herdr on the computer, then test the connection again.

How do notifications work? What gets installed?

  • You need Purrdr Plus and a macOS or Linux host (with sh and curl).
  • Turn on notifications for the selected host in “⋯ → Settings”. With your consent, Purrdr runs herdr plugin install on the host to add a small herdr plugin (open source: raychiutw/purrdr.host) and writes this device’s pairing file under ~/.purrdr/.
  • When an agent needs you, the plugin sends only the workspace name, the status, and the pane ID to Purrdr’s server, and Apple delivers the notification to your device. Conversation content is never sent. Tapping the notification opens that chat.
  • Turning notifications off or removing the host removes this device’s pairing; when the last device turns them off, the plugin Purrdr installed is removed too.
  • The Demo host can’t send notifications — choose your own host first.

Subscribing to Purrdr Plus, managing, and canceling

  • Purrdr Plus is monthly or yearly, each with a 2-week free trial for new subscribers. It adds notifications when an agent needs you and your host list synced across your devices.
  • Before subscribing, sign in to a member account with Sign in with Apple or Google (“⋯ → Member”). The subscription belongs to that member.
  • To manage or cancel: iOS Settings › Apple Account › Subscriptions, or “⋯ → Purrdr Plus → Manage Subscription” in the app (shown while you’re subscribed).
  • Deleting your member account doesn’t cancel an Apple subscription; cancel it separately.

Restoring purchases

  • On a new device or after reinstalling, sign in to the same member first, then go to “⋯ → Purrdr Plus → Restore Purchases”.
  • An App Store subscription belongs to one Purrdr member. If you see that this Apple account’s subscription belongs to another member, sign in the way you did when you subscribed, or link both sign-in methods to the same member on the Member screen.

Redeeming an offer code

  • In the app: sign in, then go to “⋯ → Purrdr Plus → Redeem Code” and enter the code.
  • From a redemption link or the App Store: after redeeming, open Purrdr and sign in — the subscription attaches automatically. If it doesn’t show up, tap “Restore Purchases”.
  • Current offer codes are for Apple accounts that have never subscribed to Purrdr Plus.

Deleting your member account and data

“⋯ → Member → Delete Member…” immediately deletes your member account, push pairings, and synced hosts. See the Privacy Policy.
