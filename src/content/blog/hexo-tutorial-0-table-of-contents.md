> Hexo 是一個使用 Node.js 為基礎的靜態網站產生器。使用 Markdown 解析文章，透過主題產生靜態檔案。而且他是由台灣人所開發出來的。

## 優點

- 台灣人開發，中文資源豐富。
- Node.js 生態完整，插件完整。
- 頁面產生速度快。

## 缺點

- Node.js 插件眾多，依賴複雜，有可能會踩坑。
- Hexo \_config.yaml 與 Hexo Theme \_config.yaml 交互設定較複雜。
