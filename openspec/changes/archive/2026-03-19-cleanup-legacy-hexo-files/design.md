# Design: Cleanup Legacy Hexo Files

## Judgment Criteria

### Files/Directories to KEEP (Astro project)

| Path                                  | Reason                                                |
| ------------------------------------- | ----------------------------------------------------- |
| `src/`                                | Astro source code                                     |
| `public/`                             | Astro static assets (including `public/images/blog/`) |
| `dist/`                               | Astro build output (gitignored)                       |
| `.astro/`                             | Astro generated types (gitignored)                    |
| `.github/`                            | GitHub Actions workflows                              |
| `node_modules/`                       | Dependencies (gitignored)                             |
| `tests/`                              | Playwright E2E tests                                  |
| `openspec/`                           | OpenSpec documentation                                |
| `.claude/`                            | Claude Code configuration                             |
| `.superpowers/`                       | Superpowers configuration                             |
| `package.json`, `pnpm-lock.yaml`      | Package management                                    |
| `astro.config.mjs`, `tsconfig.json`   | Astro/TypeScript config                               |
| `tailwind.config.mjs`                 | Tailwind CSS config                                   |
| `.eslintrc.cjs`, `.prettierrc`        | Linter/formatter config                               |
| `vitest.config.ts`, `vitest.setup.ts` | Unit test config                                      |
| `playwright.config.ts`                | E2E test config                                       |
| `CLAUDE.md`, `.gitignore`             | Project docs and git config                           |

### Files/Directories to DELETE (Hexo legacy)

**Identification signals:**

1. **Timestamp**: All files had `Mar 19 09:14` timestamp (initial clone), indicating they were never modified in the Astro era
2. **Content type**: Static HTML pages with Hexo-specific markup (Material theme, Hexo meta tags)
3. **Directory structure**: Hexo's output pattern -- year directories, flat `archives/`, `categories/`, `tags/` at root
4. **Vendor libraries**: `lib/` containing jQuery, Velocity.js, etc. -- bundled by Hexo theme, not used by Astro
5. **XML feeds**: `atom.xml`, `search.xml`, `sitemap.xml` -- generated by Hexo plugins; Astro generates its own via `@astrojs/sitemap` and `@astrojs/rss`
6. **Root `index.html`**: Hexo's homepage; Astro generates its own in `dist/`
7. **Root `robots.txt`**: Old version; new one lives in `public/robots.txt`

### Special Cases

- `public/images/blog/` -- KEPT. These are blog post images referenced by Astro content.
- `images/` (root) -- DELETED. These were Hexo theme assets (e.g., `default_thumbnail.png`).
- `page/` -- DELETED. Hexo pagination output (page/2/, page/3/).
- `favicon.ico` -- Did not exist at root level, no action needed.
