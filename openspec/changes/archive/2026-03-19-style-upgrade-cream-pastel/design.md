## Context

部落格已完成 Astro 遷移（27 篇文章、69 頁），但 Key User 認為現有極簡風格太素且字體不適合。需要將整體視覺升級為「奶油暖甜」風格。

## Goals / Non-Goals

**Goals:**

- 全站色彩系統從冷色調改為暖色調（奶油黃 + 暖棕）
- 字體從襯線體改為無襯線的 Noto Sans TC
- 標籤使用珊瑚橘 + 抹茶綠等暖色系
- 程式碼區塊配合暖色調整
- 深色模式適配暖色系
- 保持所有現有功能不變

**Non-Goals:**

- 不改變頁面佈局和結構
- 不改變功能邏輯
- 不新增頁面或元件

## Decisions

### 色彩系統

**明亮模式：**
| 用途 | 現有 | 更新 |
|------|------|------|
| 背景 | #FAFAF9 (冷白) | #FDF6EC (奶油黃) |
| 文字 | #1C1917 (深灰) | #3E2723 (暖棕) |
| 次要文字 | #666 | #795548 |
| 強調色 | #2563EB (藍) | #FF9A76 (珊瑚橘) |
| 連結色 | #2563EB | #E65100 (深橘) |
| 邊框 | #E5E7EB | #D7CCC8 |
| 程式碼背景 | #F5F5F4 | #FFF3E0 |
| 行內代碼背景 | #F5F5F4 | #FFF8E1 |

**深色模式：**
| 用途 | 更新 |
|------|------|
| 背景 | #1A1410 (暖深棕) |
| 文字 | #E8DDD0 (暖白) |
| 次要文字 | #A89080 |
| 強調色 | #FFB088 (淺珊瑚) |
| 連結色 | #FFB088 |
| 邊框 | #3E3028 |
| 程式碼背景 | #231C14 |

### 字體

- 標題：`'Noto Sans TC', system-ui, sans-serif`（font-weight: 700）
- 內文：`'Noto Sans TC', system-ui, sans-serif`（font-weight: 400）
- 程式碼：`'JetBrains Mono', monospace`（不變）
- Google Fonts import 從 Noto Serif TC 改為 Noto Sans TC

### 標籤配色

使用暖色系分類標籤：

- 珊瑚橘：`bg-#FFCCBC text-#BF360C`（預設）
- 抹茶綠：`bg-#C8E6C9 text-#2E7D32`
- 奶茶棕：`bg-#D7CCC8 text-#4E342E`
- 薰衣草：`bg-#E1BEE7 text-#6A1B9A`
- 天空藍：`bg-#B3E5FC text-#01579B`

### 品牌 Logo

Header 站名前加圓形 Logo：

- 24x24px 圓形
- 背景色 #FF9A76（珊瑚橘）
- 內容：白色 "R" 字母

## Risks / Trade-offs

| 風險                       | 緩解                                     |
| -------------------------- | ---------------------------------------- |
| 暖色調可能影響程式碼可讀性 | 程式碼區塊使用獨立背景色，保持足夠對比度 |
| 深色模式配色需重新驗證     | 所有色彩需通過 WCAG AA 對比度 4.5:1      |
